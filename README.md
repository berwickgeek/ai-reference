# ai-reference

Reference data and small tools for building with AI: lists, lexicons and checks we needed, could not find published, and made ourselves. Each folder is one resource with its own README.

| Folder | What it is |
|---|---|
| [`tts-place-names`](tts-place-names) | Place names a text-to-speech voice says wrongly, with IPA checked by ear that fixes them (Deepgram Aura-2) |
